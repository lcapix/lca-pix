# The walkthrough film

"LCAPIX for teaching and research: the new app, screen by screen". A narrated film, 1920 by 1080, with captions and chapters, about 8 and a half minutes. Kavish sends the MP4 (`LCAPIX-walkthrough.mp4`) separately; it is not in git.

It follows one worked example from start to finish: Dr. Elena Rivera, a professor at State University, arrives from the website, reads a finished sample study (a painted steel bracket, 1.72 kg CO₂-eq), tries it on her own copy, starts her own project from a file, then runs a class project. Ana Ruiz is one of her students. Every screen appears when it happens to Elena or Ana, as it was exported from Paper, never redrawn.

The film shows the screens as designed. What today's code does, and what it still needs, is in `../build-map.md`.
